Welcome to the **IVA TIME** wiki! This wiki contains complete project documentation, usage guides, technical references, and developer guides.

### About the Project

IVA TIME is a bilingual (Persian and English) world clock application built with pure HTML, CSS, and JavaScript. This project requires no external dependencies.

## 🌟 Project Highlights

- ✅ **Pure Vanilla JS** — No frameworks, no build step
- ✅ **Zero Dependencies** — Works everywhere
- ✅ **Bilingual** — Persian (RTL) + English (LTR)
- ✅ **NTP Sync** — Millisecond-accurate time
- ✅ **Responsive** — Mobile-first design
- ✅ **Accessible** — Keyboard navigation, ARIA labels
- ✅ **SEO Friendly** — Semantic HTML
- ✅ **Open Source** — MIT License
