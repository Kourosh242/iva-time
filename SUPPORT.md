- 🇫🇷 French

### How to Add a Language

1. Fork the repository
2. Add translations in `app.js`:

```javascript
const C = {
  en: {/* English */},
  fa: {/* Persian */},
  // Add new language:
  ar: {/* Arabic */},
};
```

3. Update language switcher
4. Submit PR
